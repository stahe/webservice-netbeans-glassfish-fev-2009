# Service Web Java EE avec NetBeans 6.5 et GlassFish

👉 **Tutoriel associé :**
[Construire un service web Java EE avec l'IDE Netbeans 6.5 et le serveur Java EE Glassfish](https://stahe.github.io/webservice-netbeans-glassfish-fev-2009/)

---

## 📌 Objectif du tutoriel

Ce tutoriel présente les étapes nécessaires à la **création et au déploiement d’un service web Java EE (J2EE)** à l’aide de :

* l’IDE **NetBeans 6.5**
* le serveur d’applications **GlassFish** intégré

Il montre également comment développer et tester **plusieurs types de clients** consommant ce service web :

* Client Java
* Client C#
* Client ASP.NET
* Client Flex

Le code n’est pas détaillé ligne par ligne. Ce document s’adresse donc à des développeurs disposant déjà d’une première expérience avec :

* Java EE
* EJB 3
* JPA
* NetBeans

## 🏗️ Contenu pédagogique

Le tutoriel couvre notamment :

* La conception du service web Java EE
* Le déploiement sur le serveur GlassFish
* L’accès aux données via JPA
* La consommation du service web par différents environnements technologiques :

  * Java SE
  * .NET (C#, ASP.NET)
  * Flex

Les concepts fondamentaux utilisés (EJB3, JPA, architecture Java EE) sont supposés connus ou abordés dans des ressources complémentaires référencées dans le tutoriel.
